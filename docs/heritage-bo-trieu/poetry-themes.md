# Theme tags — thơ Ông Triệu

Dùng khi OCR + steward review. Gắn 1–4 tag / bài.

| Tag | Ý |
|-----|---|
| `vo_chong` | Tình nghĩa vợ chồng, anh–em |
| `con_cai` | Con cái, lời khuyên con |
| `gia_dinh` | Gia đình hạt nhân, nhà cửa, sinh hoạt |
| `nghe_giao` | Nghề giáo, học trò, khoa học, nhà giáo |
| `tho` | Meta về thơ, chiếu thơ, cầm kỳ thi họa |
| `biet_on` | Biết ơn, duyên nợ, nhớ người đã khuất / thầy bạn |
| `truyen_thong` | Quê Bắc Ninh, gia tộc, truyền thống |

## Quote mode

- **Default:** `paraphrase` — mượn ý tứ / khí thơ, không bắt buộc nguyên văn.  
- **Toggle `verbatim`:** trích ngắn + **ghi tên bài**; không bịa thêm câu thơ.

## Signature poems (câu hỏi #8 — giải thích)

Một số bài nên **luôn** có trong Profile/System Prompt (2–3 bài), dù RAG không retrieve — vì chúng định nghĩa “chữ ký” giọng bố (vd. tuổi bảy nhăm, bài tặng vợ, bài về nghề giáo).

Sau OCR 20 bài hiện có: script sẽ đề xuất candidates → mẹ + steward chọn.
